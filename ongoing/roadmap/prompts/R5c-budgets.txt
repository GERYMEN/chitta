DEFAULTS (orchestrator; owner may override later):
D-a Budgets live in a NEW table `budgets` (numbered migration 13, never edit
    old ones): id TEXT PK, category_id TEXT (nullable — NULL = the overall
    budget), amount_minor INTEGER NOT NULL, period TEXT NOT NULL DEFAULT
    'monthly' (only 'monthly' used now; column keeps the door open),
    created_at TEXT NOT NULL, updated_at TEXT NOT NULL. Index on (category_id).
    The repository ENFORCES at most one overall budget (category_id NULL) and
    at most one budget per category_id (upsert by key: set replaces, not
    duplicates). Backup/restore (backup.tables.ts, sinceVersion 13) includes
    it; restore of an old backup without the table still works.
D-b "Monthly" = the CURRENT CALENDAR MONTH (monthKeyOf(now)), not the trailing
    selectedPeriod window. Budget "actual" for a category = spendByCategory
    over [first of this month 00:00 local .. now], matched by categoryId.
    Overall actual = periodTotals(...).expenseMinor over the same range (or the
    sum of category spendContribution — use the existing helper, one source of
    truth). Clock via useNow so it rolls at month boundary / on focus.
D-c Progress state from actual/budget ratio: under 0.8 = normal (green),
    0.8..1.0 inclusive-ish = amber (warning), over 1.0 = over (red). Expose a
    pure helper budgetState(actualMinor, budgetMinor) returning
    'under'|'near'|'over' (budget<=0 -> treat as unset). Colors from the
    theme / CATEGORY_COLOR_KEYS (green/amber/red), not hardcoded hex.
D-d Budgets screen (new, src/features/budgets/): top = overall monthly budget
    with a progress ring/bar (actual vs budget, state color, "₹X of ₹Y",
    "₹Z left" or "₹Z over"); Set/Edit overall. Below = per-category budgets
    list, each row: category name + icon/color, bar, actual/budget, state.
    "Add budget" -> pick a category (EXPENSE or BOTH kinds only; exclude the
    system transfer category and income-only; Uncategorised allowed) + amount.
    Edit amount; Remove with a 5 s Undo (shared Snackbar). Amount validation
    (> 0). >=48 dp targets, a11y labels/roles (radio role/state on the
    category chooser). Archived category: its budget stays in the data but is
    hidden from the list (not auto-deleted — undo-friendly).
D-e Home Budget card (new): shows only when at least one budget is set —
    overall month progress (ring/bar + state color) and, if any category is
    over or near, a one-line "N over budget" / "N near limit"; tap opens the
    Budgets screen. All amounts via AmountText/formatRupeesFromMinor so the
    redaction flag masks them. Slots near WhereItWentCard on Home. Also add a
    Budgets entry from Settings.
D-f Budgets NEVER change balances or transactions — they are a read-only
    overlay on spend. Setting/removing a budget only writes the budgets table
    + an audit row.
D-g Audit: budget_set / budget_updated / budget_deleted (metadata =
