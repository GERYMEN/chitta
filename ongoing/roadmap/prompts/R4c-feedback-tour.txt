PART A — Floating feedback widget (one widget, mounted once above the
navigator so it floats over every main screen)
A1 Visual: one circular button, diameter 52dp, feedback icon
   (react-native-vector-icons), theme tokens, accessibilityLabel "Send
   feedback". Never more than one trigger; no speed-dial.
A2 State machine (pure reducer, unit-tested): DOCKED → (tap) EXPANDED →
   (tap) CAPTURING_SCREENSHOT → FEEDBACK_MODAL_OPEN; EXPANDED → (3000 ms
   no touch) SNAPPING → DOCKED; any → (drag) DRAGGING → (release)
   SNAPPING → DOCKED. Tap on DOCKED only expands (does NOT open the
   sheet).
   - DOCKED: snapped to left or right edge, ~65% off-screen (~35%
     visible), opacity 0.3, subtle border + shadow.
   - EXPANDED: fully visible 16dp from the edge, opacity 1, spring.
   - DRAGGING: movement ≥ 6dp turns a tap into a drag; scale 1.08,
     stronger shadow, follows the finger (transform translate, native
     driver), timer cleared.
   - SNAPPING: spring to the nearest horizontal edge (x < width/2 → left,
     else right), keeping the release Y.
   - Y clamped between the top safe area + header (≈72dp + radius) and
     the bottom tab bar + safe area (≈88dp + radius); use real insets.
   - Persist side + Y locally across launches (settings key; not
     audited).
   - Accessibility: when a screen reader is on, a single tap opens the
     sheet directly (two-tap pattern is hostile to TalkBack).
   - Hidden during onboarding/setup screens, while the keyboard is open,
     while the feedback sheet is open, and during the tour except the
     tour step that points at it.
A3 Screenshot capture (own Kotlin module, e.g. FeedbackModule):
   - captureScreen(): capture the current Activity window to a PNG in
     the app CACHE dir (cache/feedback/), PixelCopy on API 26+ (fallback
     to drawing the decor view), return file uri/path + size. Delete old
     feedback screenshots on each capture and on app start.
   - Before capturing: hide the widget (excluded from the image) and
     switch the app into REDACTED mode, wait for the frame to render,
     capture, then restore. REDACTED mode masks: all money amounts
     (route through formatRupeesFromMinor / AmountText — "₹ ••••"),
     merchant/payee names and notes in rows/details (TransactionRow +
     detail screens), SMS descriptions/original SMS, account last-4 and
     the user's name. Implement as one global flag (store) read by the
     shared components; list in the report any screen text that is NOT
     covered.
   - Never log, upload or keep the image anywhere except the cache file
     until shared/removed.
