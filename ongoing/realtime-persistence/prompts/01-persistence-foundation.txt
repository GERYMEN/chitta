F2. Schema — create `src/data/db/schema/` with the table definitions (as SQL
    strings, one file per table is fine, or one `schema.ts` file — your
    call, keep it readable). Exact columns:

    ```sql
    CREATE TABLE IF NOT EXISTS accounts (
      id TEXT PRIMARY KEY,
      name TEXT NOT NULL,
      type TEXT NOT NULL,
      last_four TEXT,
      opening_balance_minor INTEGER NOT NULL,
      currency TEXT NOT NULL,
      is_active INTEGER NOT NULL DEFAULT 1,
      created_at TEXT NOT NULL,
      updated_at TEXT NOT NULL
    );

    CREATE TABLE IF NOT EXISTS categories (
      id TEXT PRIMARY KEY,
      name TEXT NOT NULL,
      parent_id TEXT,
      type TEXT NOT NULL,
      icon TEXT NOT NULL,
      is_system INTEGER NOT NULL DEFAULT 0
    );

    CREATE TABLE IF NOT EXISTS transactions (
      id TEXT PRIMARY KEY,
      type TEXT NOT NULL,
      status TEXT NOT NULL,
      amount_minor INTEGER NOT NULL,
      currency TEXT NOT NULL,
      merchant_name TEXT NOT NULL,
      category_id TEXT NOT NULL,
      account_id TEXT NOT NULL,
      payment_method TEXT NOT NULL,
      occurred_at TEXT NOT NULL,
      detected_at TEXT NOT NULL,
      approved_at TEXT,
      note TEXT,
      source_type TEXT NOT NULL,
      source_reference_hash TEXT,
      sanitized_preview TEXT,
      confidence_score REAL,
      parser_version TEXT,
      created_at TEXT NOT NULL,
      updated_at TEXT NOT NULL,
      FOREIGN KEY (category_id) REFERENCES categories(id),
      FOREIGN KEY (account_id) REFERENCES accounts(id)
    );

    CREATE TABLE IF NOT EXISTS audit_events (
      id TEXT PRIMARY KEY,
      transaction_id TEXT,
      event_type TEXT NOT NULL,
      event_at TEXT NOT NULL,
      actor TEXT NOT NULL,
      metadata_json TEXT,
      FOREIGN KEY (transaction_id) REFERENCES transactions(id)
    );
    ```

    Booleans (`is_active`, `is_system`) stored as INTEGER 0/1 — SQLite has no
    native boolean, map to/from JS `boolean` in the mapper layer (F4), never
    leak the 0/1 INTEGER into domain objects.
